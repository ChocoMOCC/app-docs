Portal directory

Find applications

Home displays the applications available to the current visitor and active role.

  • Enter part of an application name in Search applications.
  • Select All or a configured category to narrow the grid.
  • Clear the search and choose All to restore the complete permitted directory.
  • If no results appear, check spelling, the selected category, sign-in state, and active role.
Role-aware results

Administrator can access every configured application. Other users see public applications plus applications assigned to their active role.
