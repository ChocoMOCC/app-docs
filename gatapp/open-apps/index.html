Launch behavior

Open applications

Source typeWhat happensUse case
LinkThe portal navigates to the configured address.Standalone websites and services.
EmbedThe application loads in a sandboxed portal frame.Web tools intended to run inside GAT App.
CodeConfigured HTML runs in a sandboxed frame.Small, self-contained internal utilities.

A loading state remains visible while an embedded application starts. Each successful launch contributes to the administrator's 30-day usage analytics.

Sandbox limits

Embedded tools may use scripts, forms, same-origin content, and popups. Browser or destination security policy can still prevent a site from loading inside a frame.
