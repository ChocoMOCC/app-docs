Getting started

The public portal shows applications available to everyone. Sign in when you need personalized favorites or role-restricted applications.

1

Open Home

Use Home in the sidebar or the GAT App brand in the header to return to the portal directory.

2

Find the application

Search by application name, select a category, or browse Favorites when signed in.

3

Open it

Select the application card. Links open their destination; embedded and code applications run inside the portal.

4

Sign in if required

Use your registered email address and NIM. Select an assigned role when different work requires a different access context.

Application not visible?

The portal filters applications on the server. Sign in and select a role allowed by that application; unavailable tools are not merely hidden by the browser.
