Administrator

Home content

System Settings → Home controls optional content shown above the application directory.

Custom HTMLRender administrator-provided markup in the Home content area.
Embed URLLoad a configured page in the Home frame.
  1. Select Custom HTML or Embed URL.
  2. Enter the complete HTML or destination address.
  3. Save Home Content and wait for the saved confirmation.
  4. Return to Home and verify the result at desktop and mobile widths.
Blank Home content

Leaving the value empty intentionally produces a clean portal directory without an additional content panel.
