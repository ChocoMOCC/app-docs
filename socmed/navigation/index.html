Workspace basics

Navigation

On desktop, use the left sidebar. On mobile, Home, My Work, Planner, and Library stay in the bottom bar; open More for the remaining permitted views. The current view is written to the URL, so browser Back and Forward work as expected.

ViewUse it forAvailable to
DashboardKPIs, growth charts, records, and daily context.All roles
My WorkTasks assigned to the signed-in creator.Creator, Admin
CalendarDate-based planning and calendar image export.Creator, Admin
Task ListSearch, filter, sort, create, and edit scheduled work.Creator, Admin
Posts libraryDevelop backlog drafts, hooks, scripts, captions, and references.Creator, Admin
Meeting MemoRecord decisions, participants, links, and formatted notes.Creator, Admin
AnalyticsContent, creator, platform, and category reporting.All roles
Web AnalyticsWebsite traffic and page performance.All roles
SettingsWorkspace configuration and administration.Admin
Mobile note

Restricted views do not appear until the workspace is unlocked. If a destination is missing, confirm both your role and lock state.
