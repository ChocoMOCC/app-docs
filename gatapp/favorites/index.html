Favorites

Signed-in users can mark frequently used applications as favorites. Favorite applications appear in a dedicated section at the top of Home when no search or category filter is active.

  1. Sign in to your GAT App account.
  2. Select the favorite control on an application card.
  3. Return to Home with Search empty and category set to All.
  4. Select the control again to remove the favorite.

Favorites belong to the authenticated user and are synchronized through the portal service; they are not merely stored in the current browser.
