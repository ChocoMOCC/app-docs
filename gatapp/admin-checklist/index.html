Change control

Administrator checklist

  1. Confirm the application owner, intended audience, and launch mode.
  2. Test the source directly before adding it to the portal.
  3. Assign the narrowest correct roles and verify with a non-administrator account.
  4. For embeds, verify the destination permits framing and required sandbox capabilities.
  5. Run an application health check after publishing.
  6. Review the audit event and confirm the application appears in the intended order.
