Portal basics

Navigation

ControlPurpose
GAT App logoReturn to Home from any portal view.
Sidebar menuOpen Home or any application allowed for the active role.
Nine-dot menuCollapse or restore the application sidebar.
Sign In / user menuAuthenticate, review the active role, switch roles, or sign out.
System SettingsOpen administration tools; shown only to an Administrator.

Application routes use readable slugs. Browser Back and Forward return through previously opened portal views. Unknown, inaccessible, or unavailable routes show a dedicated recovery page with Home and Back or Retry actions.
