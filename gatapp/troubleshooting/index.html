Troubleshooting

An application is missing +

Clear search and category filters. Then sign in and choose the role assigned to that application. Ask an Administrator to review Allowed roles if it remains unavailable.

An embedded application never loads +

Open another application to confirm connectivity, then retry. The destination may reject iframe embedding or may be down; an Administrator can run its health check.

Sign in fails +

Use the email and NIM registered in Central Auth. After repeated attempts, wait before retrying because login requests are rate-limited.

I cannot switch to a role +

You may select only roles assigned to your account. A Superadmin must update the Central Auth user record when an assignment is missing.

System Settings is missing +

System Settings requires an authenticated Administrator active role. Switch roles if Administrator is already assigned to your account.

User management asks for another passcode +

This is expected. Sensitive user operations require temporary Superadmin elevation in addition to Administrator access.

A route says unavailable or not found +

Use Go to home and search for the application again. The application may have been renamed, removed, restricted, or temporarily unavailable.

My favorite is not saved +

Confirm you are signed in. Favorites are user-specific and require a valid authenticated session.

Escalation checklist

Include the application name, route, local time, active role, observed message, and a screenshot with credentials removed.
