Administrator

Manage applications

Administrators use System Settings → Apps to add, edit, delete, and reorder portal applications.

FieldGuidance
NameUse a short, unique label users will recognize.
Source typeChoose Link, Embed, or Code based on the launch behavior.
SourceEnter the destination URL or complete HTML source.
IconSelect a built-in icon used when no image is configured.
Image URLOptional logo shown on portal cards and navigation.
CategoryChoose Apps, Tools, Resources, or define a custom category.
Allowed rolesSelect Public or one or more roles; Administrator always retains access.

Use the up and down controls to change portal order. Deletion is permanent after confirmation, so verify the application name first.
