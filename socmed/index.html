Start here

Getting started

Socmed Apps combines the publication database, content backlog, schedule, meeting records, and performance reporting in one workspace.

Before you begin

  • Use the role and access key assigned by the workspace administrator.
  • Use a current desktop or mobile browser with JavaScript enabled.
  • Confirm the date range in the top bar before reviewing totals or charts.
1

Unlock the workspace

Select Viewer, Creator, or Admin, then enter the matching access key. A refresh or session timeout locks restricted areas again.

2

Check your queue

Creators start in My Work. Resolve Overdue and Due Today items before upcoming work.

3

Move work through the system

Schedule the task, develop its draft in Posts library, then let the published database entry mark the task as uploaded.

4

Review results

Set a reporting range, then compare views, reach, engagement, creators, categories, and platforms.

Data model

A scheduled task, a Posts library draft, and a published database row are separate records. Use a consistent title, date, PIC, and category so the app can relate planning work to publication results.

03

At a glance

Dashboard

The Dashboard summarizes performance and operational activity for the selected date range.

Performance cards

Review total views, published content, reach, engagement, and average engagement rate. Change the global date range to compare reporting periods.

Growth Performance

Switch between Followers, Engagement, and Reach. Each line represents Instagram, TikTok, or YouTube. Followers are cumulative; engagement and reach show monthly totals.

Reading the chart

A flat line may be valid when the selected period has no recorded metric. If axes and month labels are missing too, refresh and check your connection.

04

Personal queue

My Work

My Work shows schedule entries assigned to your user ID, with a name-based fallback for older records. Creators land here after unlocking.

  • Work in order: Overdue, Due Today, then On Progress.
  • Open an item to review its scheduled date, PIC, category, and title.
  • A task becomes Done when a matching uploaded publication record exists; it is not a separate manual workflow state.
  • Use Calendar for team context or Task List for search, filters, and sorting.
05

Plan delivery

Calendar & tasks

Calendar and Task List are two views of the same master schedule. Calendar is best for date context; Task List is best for finding and updating individual items.

Create or edit a task

  1. Choose the scheduled date. This field is required.
  2. Select the PIC and category. Both are required and use the values configured for the workspace.
  3. Add a short content title or topic. The title is optional, but strongly recommended.
  4. Save, then confirm the item appears on the intended date and under the correct PIC.

Understand timeline status

OverdueThe scheduled date has passed and no matching upload is recorded.
Due TodayThe item is scheduled for the current local date.
On ProgressThe date is upcoming and publication is not yet recorded.
DoneThe schedule item resolves to an uploaded publication record.
Deletion warning

Deleting a master schedule task can also remove its associated platform rows from the Laporan database. Check the title, date, PIC, and category in the confirmation before continuing.

06

Develop and measure

Posts & records

The Posts library stores pre-publication creative work. The Dashboard publication database stores live platform rows and measured results. They serve different stages of the workflow.

Posts library draft

FieldRequiredGuidance

Script / audioNoAdd dialogue, voice-over cues, and visual direction.

Draft state is derived as Idea, Scripting, or Uploaded. Search the backlog by title and filter it by PIC or category. Unsaved storyboard changes may be recovered from the same browser after an interruption.

Published database row

FieldGuidance
IDKeep one stable content ID across every platform row for the post.
DateUse the actual publication date, not the draft creation date.
Content TitleMatch the recognizable schedule or draft title.
PIC / CategoryUse configured values so filters and comparisons stay consistent.
PlatformSelect Instagram, TikTok, YouTube, or another configured channel.
Views / ReachEnter numbers only, using the platform-reported values.
InteractionsRecord likes, comments, follows, reposts, and shares in their own fields.
URLLink directly to the live post.
Admin-only database changes

Creators can manage schedules, drafts, and meeting memos, but only Admin can create, update, or delete master publication rows.

07

Capture decisions

Meeting memos

Meeting Memo stores date-based recaps with selected participants, reference links, and formatted detail notes.

  1. Create a memo and choose its date.
  2. Select participants; search supports both names and roles.
  3. Add any supporting links. URLs open in a new browser tab when viewing the recap.
  4. Write the required recap notes, then save.

The editor supports formatted text, lists, and links. Pasted content is sanitized so unsafe markup and conflicting colors are removed. If the browser closes mid-edit, the app can recover the unsaved memo draft in that browser.

Recommended structure

Decision: what the team agreed. · Owner: one accountable person. · Due date: a specific date. · Follow-up: the next observable action.

08

Understand results

Content analytics

Analytics uses published database rows in the active date range. Empty or unpublished rows are excluded.

  • Set the date range before drawing conclusions.
  • Use the KPI Content Explorer to filter by KPI score and content category.
  • Review the Top 5 Content Leaders and Creator Analytics Performance tables.
  • Compare the views-and-engagement trend, platform distribution, views by creator, and category share charts.
  • Check the source publication row when a value looks unusual.

Common metrics

ViewsTotal recorded content views in the selected range.
ReachPlatform-reported accounts reached.
EngagementRecorded audience actions combined by the app.
Engagement rateEngagement relative to the configured KPI calculation.
No analytics data

The analytics view requires published database rows in the active date range. Widen the range or verify the source record before treating an empty chart as an error.

09

Measure site traffic

Web analytics

Web Analytics is separate from social content reporting. Use it to review Google Analytics summary values and page-level website activity for the configured site.

  • Confirm the reporting period before comparing traffic.
  • Use page rows to identify which paths attract visits.
  • Open a configured page destination only when you need to inspect the live page.
  • Admin can maintain Google Analytics summary and item records; other roles have read access.

11

Admin reference

Settings

Settings is available only to Admin. Changes affect the options and branding shown across the workspace.

  • Maintain workspace identity, application labels, and organization details.
  • Manage members and the PIC values available in task and content forms.
  • Manage content categories and choose which categories appear in Posts library.
  • Maintain configured social platforms and their display metadata.
  • Review administrative and audit information before changing shared configuration.
Configuration impact

Renaming or hiding a category can change filters and create forms immediately. Check existing schedules, drafts, and reports before changing shared values.

12

Work outside the app

Export

The app provides two exports for different purposes. Treat both as internal operational data.

Content performance workbook

  1. Set the global date range.
  2. Choose Export from the top bar.
  3. The app downloads an Excel workbook with a Content Performance Data sheet.
  4. Verify the date range and row count before sharing or analyzing it.

Calendar image

  1. Open Calendar and choose its export action.
  2. Select Light or Dark, whether to show meetings, and optional PIC or category filters.
  3. Review the preview, then download the PNG.
  4. The filename includes the calendar month and selected theme.
13

Resolve issues

Troubleshooting

The page stays on a skeleton loader +

Wait for the current sync to finish, check your connection, then refresh once. If it continues, record the affected view, time, and network state.

The Growth Performance graph is blank +

If the legend appears but axes and lines do not, refresh once. If axes appear but lines are flat, widen the date range and confirm saved metrics exist for that period.

Analytics says there is no data +

Analytics ignores unpublished or empty rows. Confirm the active date range contains published database entries with numeric metrics.

My changes are not visible +

Confirm the save notification appeared, clear search and category/PIC/status filters, and verify the selected date range. Then use the app's synchronization action if available.

I cannot edit, delete, or see a view +

Confirm the workspace is unlocked and compare your role with the permissions table above. Creator cannot change master publication rows; Settings requires Admin.

An unsaved draft reappeared +

The app stores recoverable task, post, and meeting drafts in the current browser. Review the recovered content, then save it or discard it from the editor.

The workspace says it is offline +

The app may load a local backup. Restore the connection and use Retry sync before making further edits so the server remains the source of truth.

A shared link opens the wrong item +

Ask for a fresh link. Item URLs include view and record identifiers; the target may have been removed or your role may not permit that view.

Escalation checklist

Include the view name, record ID, local time, selected date range, role, and a screenshot with sensitive data removed.
